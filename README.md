Abstract : 
A student's academic performance is influenced by factors such as study consistency, attendance, and demographic background. 
This project builds a regression-based system to estimate exam scores using academic and demographic data. After cleaning and preprocessing the dataset,
regression models like Linear Regression and Random Forest Regression are trained and evaluated using metrics such as Mean Squared Error (MSE) and R² score.
The final system predicts exam scores based on study and attendance details, helping students improve habits and enabling educators to identify 
at-risk learners early.
